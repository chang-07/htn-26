Before any of this is built

Where these appear. Agent Apps draws the bubble on phones that have it, so every card here reaches the thread as a photo, or lives on the page behind the button. Photos cannot redraw, which is why each card has exactly two states: one photo when it opens, one when it resolves.

What ports cleanly. Everything is flex rows and columns. The perforation is a gradient here and a column of dots in the renderer, as on the plan card. The venue photo is the only remote image, and the cart card already proves those load.

Suggested order. Match intro, venue, who's in, then the order restyle. Looking-into-it last, and only if in-place redraw turns out to work for phones without the app.
